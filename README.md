# DIC3-ProjectRefactor｜交通配時助手

以**單一路口、南北／東西兩軸直行車流**為範圍，開發可解釋、可回退、可在 ARM／FPGA 邊緣平台展示的動態交通號誌配時原型。

> 專題階段：規劃與模擬驗證。未宣稱已於真實道路改善交通。

## MVP 交付
1. 相同車流輸入、相同種子下，比較固定配時與決策樹。
2. 顯示即時交通特徵、所選策略與決策路徑。
3. 感測異常與超出適用範圍時回退固定配時。
4. 輸出 KPI、板端延遲、資源與回退日誌。

## 範圍
暫不處理左轉專用相位、行人、路口協調與緊急車輛優先。硬體不得直接控制真實道路號誌；實場部署另需交通工程、安全與法規驗證。
