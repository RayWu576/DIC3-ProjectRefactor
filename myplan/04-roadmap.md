# 04｜開發路線圖與任務

## 階段與里程碑（相對週次）
| 階段 | 週次 | 工作 | 驗收 |
|---|---|---|---|
| P0 需求凍結 | W1 | 定拓撲、模板、KPI、模擬器 | 規格與設定檔 |
| P1 固定基準 | W2 | 車流模擬、固定配時、日誌 | 四情境可重現 baseline |
| P2 決策樹 | W3 | 特徵、標籤、訓練、規則解釋 | 三類策略分類與路徑 |
| P3 安全回退 | W4 | 品質檢查、相位約束、故障注入 | 合法配時與回退日誌 |
| P4 實驗 | W5 | 多種子配對測試、KPI、圖表 | 完整對照結果 |
| P5 板端 | W6 | ARM 推論、FPGA 選用、延遲測試 | 一致性與資源報表 |
| P6 展示 | W7 | Dashboard、Demo、報告 | 展示輸入→決策→結果 |

## Must Have
- [ ] 確定模擬器、ARM／FPGA 板卡及環境
- [ ] 定義固定週期、綠燈比例與相位約束
- [ ] 完成固定配時 baseline 與四大情境
- [ ] 統一輸入 schema、資料品質檢查
- [ ] 訓練受限深度決策樹與可解釋規則
- [ ] 實作三策略、限制檢查與 fallback
- [ ] 匯出逐週期日誌與 KPI
- [ ] ARM 推論與延遲量測
- [ ] 多種子配對實驗與最終報告

## Should Have
- [ ] 儀表板顯示方向車流與策略切換
- [ ] 偵測長期單軸飢餓與配時震盪
- [ ] 感測缺值、逾時、超界故障注入
- [ ] FPGA 計數或簡易比較模組及資源量測

## Could Have
- [ ] 感測噪音／交通波動敏感度測試
- [ ] 動態展示決策樹節點、回退原因
- [ ] 擴充多路口、轉彎或行人相位（需另行安全設計）

## 風險處理
| 風險 | 緩解 |
|---|---|
| 模型標籤只反映人為偏好 | 透過離線三策略比較產標籤；保留未見測試資料 |
| 極端飽和無法改善 | 誠實呈現容量極限，不保證全面改善 |
| 感測噪音與配時震盪 | 有效性檢查、視窗平滑、切換限制 |
| 非法相位指令 | 獨立約束檢查、安全邊界與回退測試 |
| FPGA 整合延誤 | ARM 優先，FPGA 列為擴充 |
| 模擬結果被誤解為實場成果 | 清楚揭露假設與限制 |

## Demo 腳本
1. 載入 NS-heavy，顯示雙軸到車數與隊列。
2. 顯示 `NS_PRIORITY` 的決策樹路徑。
3. 與固定配時比較等待、排隊曲線。
4. 注入感測故障並顯示 `FALLBACK` 與原因。
5. 展示板端推論延遲、資源與尚待驗證項目。

## Definition of Done
系統可操作、實驗可重現、成效可回溯原始紀錄、決策可追溯、回退有測例、硬體性能有方法且明確區分預期／實測／文獻數據。
